# Taskeroid Feature Ideas

## Gameplay and Task Mechanics
- Task chains: allow dependencies so one asteroid only appears after another is completed.
- Priority decay: lower urgency tasks slowly drift outward if ignored, while near-deadline tasks accelerate inward.
- Focus mode: temporarily highlight one task asteroid and dim all others for distraction-free work.
- Mission types: support repeatable tasks (daily/weekly) that respawn with new deadlines.

## Visual and Animation Enhancements
- Planet shield pulses: when a task is completed, a ripple shield expands from the planet.
- Color themes: quick presets for radar green, amber tactical, icy blue, red alert, etc.
