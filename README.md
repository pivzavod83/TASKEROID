## `01` · MISSION BRIEFING

> Taskeroid is not a to-do list.
>
> It is a **living space simulation** — your work rendered as an asteroid field closing in on a planet. Deadlines become **orbital pressure**. Priority becomes **gravitational mass**.
>
> The closer the deadline, the closer the asteroid gets.
> The higher the importance, the **bigger the threat**.
>
> *You do not just track tasks. You command a system under pressure.*

<br/>

## `02` · COMBAT ADVANTAGES

<div align="center">

| ◈ FEATURE | ⌬ DESCRIPTION |
|:---|:---|
| 🔴 **Visual Urgency** | Deadlines feel real because you can see them closing in — not as numbers, but as mass and orbital distance |
| 🟡 **Priority at a Glance** | Important tasks are physically larger. Threat level reads instantly across the entire field |
| 🔵 **Focus Mode** | Isolate one mission. Dim the noise. Full targeting on a single incoming object |
| 🟢 **Dependency Chains** | Block tasks until prerequisite work clears. Mission chains. No task moves without authorization |
| 🟠 **Repeat Logic** | Daily and weekly tasks regenerate automatically. Recurring threats are always in the field |
| ⚪ **Immersive HUD** | Futuristic HUD panel, interactive planet, animated completion effects — zero spreadsheet aesthetics |

</div>

## `04` · DEPLOYMENT INSTRUCTIONS

Pick the branch that matches your target platform. Setup and installation details are documented **inside each branch** — instructions stay accurate for that specific target.

```bash
# Clone the repository
git clone https://github.com/your-username/taskeroid.git

# Switch to your target branch
git checkout app-dev    # Windows desktop app
git checkout wb-dev     # Public website
git checkout mac-dev    # macOS wallpaper version

# Follow the setup guide in that branch's README
```
